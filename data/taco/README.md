# Fonte dos dados

Tabela Brasileira de Composição de Alimentos (TACO), 4ª edição ampliada e revisada, NEPA/UNICAMP (2011).
CSVs normalizados obtidos de https://github.com/raulfdm/taco-api (MIT), pasta `references/csv`.
Valores por 100 g de alimento. Campos vazios = "não informado" na tabela original.

Regenerar `public/foods.json`: `npm run build:foods`.
